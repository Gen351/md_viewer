# MARKDOWN FILE EDITOR AND VIEWER

> Initial design brief for the project. The app has since been built and
> extended well beyond this spec — see `../README.md` for the current feature set.

## Look and Feel 
- It should feel modern-minimalist. Switching from light mode to dark mode is possible.

## View
- It will have a split view of the markdown file you are editing and the markdown look.

## Header
- Have buttons to change the view from split (editing and viewing), focus(only editing), and only viewing.
- Have buttons to change from light mode to dark mode.
- Have buttons to save and open a .md file.

## Functionality
- It update the view side at each character(Implement such that it will not cause lag at each character typed).

## Implementation
- Implement using HTML and JS.
